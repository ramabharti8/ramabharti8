## Problem-Solving Case Studies

<details>
<summary><b>Case Study 1: API Latency Crisis — Trading Platform (click to expand)</b></summary>

**Problem:** Trading platform experiencing 800ms+ API latency during market hours, causing user complaints and timeouts.

**Root Cause:**
- N+1 query problem — portfolio endpoint hitting DB 500+ times per request
- Missing indexes on frequently queried columns
- Connection pool exhaustion under concurrent load

**Solution:**
- Added composite indexes on `(user_id, status)` and `(created_at)` — query time 2.3s → 1.2s
- Replaced lazy loading with `select_related` / `join` loading
- Redis caching on market data with 30-minute TTL
- Tuned PostgreSQL connection pool size

**Result:** Latency 800ms → 560ms · DB queries -48% · Zero timeout complaints in prod
</details>

<details>
<summary><b>Case Study 2: Real-Time Sync in Multi-Trader Platform (click to expand)</b></summary>

**Problem:** Multiple traders viewing same portfolio getting 2-5 second stale data and write conflicts.

**Root Cause:** Pull-based polling, no conflict resolution, no optimistic locking.

**Solution:**
- Switched to WebSocket push architecture — data pushed on every trade event
- Optimistic locking with version fields for conflict detection
- FIFO queue for simultaneous trade resolution
- Event sourcing for full audit trail

**Result:** Sync latency 2-5s → <100ms · 99.8% consistency · Zero data loss in prod
</details>

<details>
<summary><b>Case Study 3: AI Hallucination in RAG System (click to expand)</b></summary>

**Problem:** Real estate AI giving inaccurate property recommendations — 60% accuracy, high hallucination.

**Root Cause:** Poor chunking strategy losing context across chunks, no similarity threshold, no verification.

**Solution:**
- Semantic chunking with 512-token overlap for context preservation
- Similarity threshold >0.75 to reject low-confidence matches
- Multi-stage metadata validation
- Confidence scoring with fallback to "I don't know"

**Result:** Accuracy 60% → 92% · Hallucinations -85% · User satisfaction 3.2 → 4.6/5
</details>
